# Hotel Management System

Developed by **Sehrish Ejaz** as part of OOP coursework at FAST-NUCES Lahore.

## Description
A C++ based Hotel Management System using OOP principles. Supports room management, guest management, booking, and billing with efficient data handling.

## Features
- Add/display rooms
- Search rooms by type and price
- Guest management (add, modify, remove)
- Room booking and release

## Tech
C++, OOP
